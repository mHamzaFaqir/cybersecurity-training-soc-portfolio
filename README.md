# Cybersecurity Training Program + SOC Analyst Portfolio

## Overview

This repository is my **master cybersecurity portfolio project**, built around the preparation and delivery of a structured cybersecurity training program. It documents not only the **teaching side** of the course, but also the **SOC analyst, blue-team, and incident-response thinking** developed through it.

The purpose of this portfolio is to show that I can:

* understand and explain cybersecurity concepts clearly
* structure technical content into a full training program
* document my work in a professional and organized way
* connect foundational and technical topics to **real SOC / blue-team thinking**
* build practical learning artifacts such as notes, cheat sheets, incident mappings, and interview prep documents

This repository is **not just a collection of class files**. It is a **career portfolio** showing my growth as:

* a cybersecurity learner
* a future SOC analyst / blue-team professional
* a cybersecurity instructor / explainer
* a documentation-focused security practitioner

---

# Portfolio Goals

This portfolio has **three main purposes**:

## 1) Document the Cybersecurity Course

## 3) Show Growth Over Time

Track how each module contributes to my development in:
